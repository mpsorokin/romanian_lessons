# Familia mea

Familia Anei este mică. Ea locuiește cu mama, tata și fratele ei.

| Română | Русский |
| --- | --- |
| mamă | мама |
| tată | папа |
| frate | брат |
| soră | сестра |
| familie | семья |

## Gramatică: posesia

Spunem **mama mea** pentru „моя мама” și **fratele meu** pentru „мой брат”. Forma se schimbă puțin, dar ideea rămâne simplă.

### Exemple

- Aceasta este **sora mea**.
- El este **fratele meu**.
- Noi iubim **familia noastră**.

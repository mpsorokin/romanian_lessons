# Lesson 18 — Mi-e foame

## Grammar ref

Состояние голода строится как `mi-e foame` — буквально «мне есть голод». Для жажды используется `mi-e sete`. Вопрос к собеседнику меняет только местоимение: `Ți-e foame?`.

`ceva de mâncat` и `ceva de băut` означают «что-нибудь поесть / выпить». Предлоги `cu` и `fără` позволяют уточнить состав: `cu carne`, `fără zahăr`. Прилагательные после этого описывают еду: `cald / rece`, `gustos`, `ușor`.

## Forms & tables

### Состояние и желание

| Română | Произношение | Значение |
| --- | --- | --- |
| **mi-e foame** | мье фоа́ме | я голоден |
| **ți-e foame?** | ць-е фоа́ме? | ты голоден? |
| **mi-e sete** | мье се́те | я хочу пить |
| **ceva de mâncat** | чева́ де мэнка́т | что-нибудь поесть |
| **ceva de băut** | чева́ де бэу́т | что-нибудь выпить |
| **cu sau fără?** | ку сау фэ́рэ? | с или без? |

### Еда и описание

| Română | Произношение | Значение |
| --- | --- | --- |
| **mic dejun** | мик дежу́н | завтрак |
| **prânz** | прынз | обед |
| **cină** | чи́нэ | ужин |
| **carne** | ка́рне | мясо |
| **pui** | пуй | курица |
| **pește** | пе́ште | рыба |
| **legume** | легу́ме | овощи |
| **salată** | сала́тэ | салат |
| **supă** | су́пэ | суп |
| **orez** | оре́з | рис |
| **cartofi** | карто́фь | картофель |
| **apă** | а́пэ | вода |

`E destul` означает «достаточно», а `Ce mâncăm?` — «Что будем есть?». Слово `bun` может означать и «хороший», и «вкусный» по контексту.

## Lesson words

Раздел содержит названия еды и отдельные прилагательные. Сочетания `mic dejun`, `ceva de mâncat` и другие готовые блоки остаются в грамматической карте, а не дублируются как отдельные фразы.

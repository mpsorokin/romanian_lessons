# Lesson 22 — Mă duc, mă uit, mă întorc

## Grammar ref

Возвратная часть показывает, что действие относится к самому участнику. Для первого лица используется `mă`, для второго `te`, для третьего `se`: `mă uit`, `te uiți`, `se uită`.

Не каждый глагол с `mă` переводится русским возвратным глаголом. `mă duc` — «я иду / отправляюсь», а `mă uit la` — «я смотрю на». Запоминай управление целиком.

## Forms & tables

### Лицо и возвратная часть

| Кто | Маркер | Пример | Значение |
| --- | --- | --- | --- |
| eu | **mă** | mă duc | я иду |
| tu | **te** | te uiți | ты смотришь |
| el / ea | **se** | se întoarce | он / она возвращается |

### Повседневные действия

| Infinitiv | Форма от 1-го лица | Перевод |
| --- | --- | --- |
| **a se duce** | **mă duc** | идти / отправляться |
| **a se uita** | **mă uit** | смотреть |
| **a se întoarce** | **mă întorc** | возвращаться |
| **a se trezi** | **mă trezesc** | просыпаться |
| **a se pregăti** | **mă pregătesc** | готовиться |
| **a se grăbi** | **mă grăbesc** | торопиться |
| **a se simți** | **mă simt** | чувствовать себя |

`mă odihnesc`, `mă întâlnesc cu...` и `mă opresc` строятся по той же модели. После предлогов сохраняй полную конструкцию: `mă uit la`, `mă întâlnesc cu`.

# Lesson 2 — Ce faci? Unde mergi?

## Grammar ref

В настоящем времени вопрос часто состоит из одного глагола: `Vii?`, `Pleci?`, `Vrei?`, `Poți?`. Личное местоимение можно добавить для контраста, но в обычной реплике оно не обязательно.

`la` обозначает направление или место (`la magazin`, `la București`), а `acasă` употребляется без `la`: «домой / дома».

## Forms & tables

Во всех таблицах ниже выделены формы, которые встречаются в уроке: `eu`, `tu`, `el / ea`.

| Кто | Present | Произношение |
| --- | --- | --- |

| tu | **faci** | фачь |
| el / ea | **face** | фа́че |
| noi | facem | фа́чем |

### Короткие вопросы и направления

| Ситуация | Română | Значение |
| --- | --- | --- |
| что делаешь? | **Ce faci?** | Что делаешь? / Как ты? |
| куда идёшь? | **Unde mergi?** | Куда идёшь? |
| сейчас | **acum** | сейчас |
| домой | **acasă** | домой / дома |
| после | **după** | после / потом |
| с кем | **cu mine / cu tine** | со мной / с тобой |

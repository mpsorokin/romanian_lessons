# Lesson 34 — Cum te simți?

## Grammar ref

Простое состояние строится как `sunt + adjective`: `sunt obosit` — «я устал», `sunt liniștit` — «я спокоен». Прилагательное согласуется с говорящим: женщина скажет `obosită`, `îngrijorată`.

Для ощущений используются модели `mi-e...`: `mi-e frică` — «мне страшно», `mi-e dor de...` — «я скучаю по...». Желание выражается через `am chef de + noun` или `am chef să + verb`, а отсутствие желания — `n-am chef`.

## Forms & tables

### Состояния и согласование

| Masculin | Feminin | Произношение | Значение |
| --- | --- | --- | --- |
| **obosit** | **obosită** | обоси́т / обоси́тэ | уставший |
| **stresat** | **stresată** | стреса́т / стреса́тэ | в стрессе |
| **liniștit** | **liniștită** | линишти́т / линишти́тэ | спокойный |
| **fericit** | **fericită** | феричи́т / феричи́тэ | счастливый |
| **trist** | **tristă** | трист / три́стэ | грустный |
| **îngrijorat** | **îngrijorată** | ынгрижора́т / ынгрижора́тэ | обеспокоенный |

### Ощущение, желание, реакция

| Модель | Значение |
| --- | --- |
| **mi-e frică** | мне страшно |
| **mi-e dor de...** | я скучаю по... |
| **am chef de...** | мне хочется чего-то |
| **am chef să...** | мне хочется сделать |
| **n-am chef** | мне не хочется |
| **mă bucur că...** | я рад, что... |
| **mă enervează** | меня раздражает |
| **mă deranjează** | мне мешает / беспокоит |

`abia aștept să...` — «не могу дождаться», а `n-am răbdare` — «у меня нет терпения». Различай `îmi place` — «мне нравится» и `mă bucur` — «я рад».

## Lesson words

В словарь входят новые прилагательные состояний и отдельные слова эмоций. Модели с `mi-e`, `am chef`, `mă` и `să` остаются в грамматическом разделе.

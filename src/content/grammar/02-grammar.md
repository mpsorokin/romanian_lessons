# Pluralul substantivelor

**Плура́лул субстанти́велор**

## Множественное число существительных

В румынском множественное число устроено сложнее, чем простое английское:

> car → cars
> restaurant → restaurants

Нельзя взять одно универсальное окончание и поставить его после любого существительного.

Вместо этого встречаются несколько очень частых моделей:

* `-i`
* `-e`
* `-uri`

а иногда при образовании множественного числа меняется ещё и сама основа слова:

**masă → mese**
**ма́сэ → ме́се**
стол → столы

**carte → cărți**
**ка́рте → кэрць**
книга → книги

**băiat → băieți**
**бэя́т → бэе́ць**
парень → парни

Поэтому множественное число лучше воспринимать не как:

> «добавь окончание по правилу»

а как:

> **у существительных существуют несколько типичных plural patterns, но важные слова полезно запоминать вместе с их формой plural.**

---

# 1. Singular и plural лучше учить вместе

Вместо:

**apartament**
**апартаме́нт**
квартира

полезнее сразу видеть:

**un apartament → două apartamente**
**ун апартаме́нт → до́уэ апартаме́нте**

---

Вместо:

**prieten**
**прие́тен**
друг

лучше:

**un prieten → doi prieteni**
**ун прие́тен → дой прие́тень**

---

Вместо:

**mașină**
**маши́нэ**
машина

лучше:

**o mașină → două mașini**
**о маши́нэ → до́уэ маши́нь**

Так одна запись сразу показывает:

* род;
* единственное число;
* множественное число;
* правильную форму `doi / două`.

---

# 2. Самые важные plural endings

Очень грубо систему можно представить так:

| Род     | Частые окончания plural | Пример                 | Транскрипция             |
| ------- | ----------------------- | ---------------------- | ------------------------ |
| мужской | `-i`                    | **prieten → prieteni** | **прие́тен → прие́тень** |
| женский | `-e`, `-i`              | **fată → fete**        | **фа́тэ → фе́те**        |
| средний | `-e`, `-uri`            | **hotel → hoteluri**   | **хоте́л → хоте́лурь**   |

Это **не универсальные правила**.

Например, женское существительное может иметь plural на `-i`, а среднее — на `-e`.

Но эти три окончания будут встречаться постоянно.

---

# 3. Мужской род: очень часто `-i`

Для существительных мужского рода чрезвычайно характерно множественное число на `-i`.

| Singular    | Транскрипция | Plural       | Транскрипция  | Значение           |
| ----------- | ------------ | ------------ | ------------- | ------------------ |
| **prieten** | **прие́тен** | **prieteni** | **прие́тень** | друг → друзья      |
| **vecin**   | **вечи́н**   | **vecini**   | **вечи́нь**   | сосед → соседи     |
| **pantof**  | **панто́ф**  | **pantofi**  | **панто́фь**  | ботинок → ботинки  |
| **coleg**   | **коле́г**   | **colegi**   | **коле́джь**  | коллега → коллеги  |
| **student** | **студе́нт** | **studenți** | **студе́нць** | студент → студенты |

Обрати внимание: plural не всегда означает просто механически добавить букву `i`.

Иногда изменяется последняя согласная или её произношение.

---

# 4. Почему конечное `-i` бывает трудно услышать

Это важная особенность именно для listening.

Например:

**prieteni**
**прие́тень**

На письме видим:

`prieteni`

Но последний `i` обычно не звучит как полноценное русское **«и»**.

Он влияет на предыдущую согласную и делает её мягче.

То же самое:

**pantofi**
**панто́фь**

**vecini**
**вечи́нь**

Поэтому в речи разница:

**prieten**
**прие́тен**

и:

**prieteni**
**прие́тень**

может сначала казаться намного менее очевидной, чем на письме.

Для понимания живой речи нужно постепенно привыкнуть слышать **смягчение конечной согласной**, а не ждать отчётливого русского окончания «-и».

---

# 5. Мужские существительные могут менять основу

Очень частый пример:

**băiat → băieți**
**бэя́т → бэе́ць**
парень → парни

Не:

> `băiati`

а:

> **băieți**

**băieți**
IPA: /bəˈjet͡sʲ/

---

Другой пример:

**frate → frați**
**фра́те → фраць**
брат → братья

**frați**
IPA: /frat͡sʲ/

---

Ещё:

**bărbat → bărbați**
**бэрба́т → бэрба́ць**
мужчина → мужчины

То есть даже если ты видишь общую модель `plural на -i`, конкретная форма всё равно иногда требует изменения основы.

---

# 6. Женский род: очень часто `-ă → -e`

Одна из наиболее полезных моделей:

> **-ă → -e**

Например:

| Singular     | Транскрипция  | Plural       | Транскрипция  | Значение            |
| ------------ | ------------- | ------------ | ------------- | ------------------- |
| **fată**     | **фа́тэ**     | **fete**     | **фе́те**     | девушка → девушки   |
| **casă**     | **ка́сэ**     | **case**     | **ка́се**     | дом → дома          |
| **stradă**   | **стра́дэ**   | **străzi**   | **стрэ́зь**   | улица → улицы       |
| **problemă** | **пробле́мэ** | **probleme** | **пробле́ме** | проблема → проблемы |

Но уже здесь видно:

**stradă → străzi**

не следует простой модели `-ă → -e`.

Поэтому опять же:

> модель помогает предполагать форму, но не заменяет знание конкретного слова.

---

# 7. Некоторые женские существительные получают `-i`

Например:

**mașină → mașini**
**маши́нэ → маши́нь**
машина → машины

**vacanță → vacanțe**
**вака́нцэ → вака́нце**
отпуск → отпуска

**limbă → limbi**
**ли́мбэ → лимбь**
язык → языки

---

Сравни:

| Singular   | Plural     | Транскрипция          |
| ---------- | ---------- | --------------------- |
| **casă**   | **case**   | **ка́сэ → ка́се**     |
| **mașină** | **mașini** | **маши́нэ → маши́нь** |
| **limbă**  | **limbi**  | **ли́мбэ → лимбь**    |
| **stradă** | **străzi** | **стра́дэ →стрэ́зь**  |

Все четыре слова женского рода, но plural patterns разные.

---

# 8. Женские существительные на `-e`

Здесь plural часто приходится просто запоминать.

Например:

| Singular   | Транскрипция | Plural    | Транскрипция |
| ---------- | ------------ | --------- | ------------ |
| **carte**  | **ка́рте**   | **cărți** | **кэрць**    |
| **noapte** | **но́апте**  | **nopți** | **нопць**    |
| **parte**  | **па́рте**   | **părți** | **пэрць**    |

**cărți**
IPA: /kərt͡sʲ/

Здесь происходит изменение не только окончания:

**carte → cărți**

Поэтому пытаться каждый раз логически вычислить такую форму неудобно.

Для частотных слов plural лучше просто узнавать автоматически.

---

# 9. Слова на `-ie`

Некоторые очень частые женские существительные заканчиваются на `-ie`.

Например:

**chirie**
**кири́е**
аренда / квартплата

Plural:

**chirii**
**кири́й**
арендные платежи / варианты аренды — в зависимости от контекста

---

**familie → familii**
**фами́лие → фами́лий**
семья → семьи

---

**conversație → conversații**
**конверса́цие → конверса́ций**
разговор → разговоры

Здесь на письме окончания иногда выглядят непривычно из-за последовательности нескольких `i`.

Но постепенно такие формы начинают восприниматься как обычные.

---

# 10. `cafea → cafele`

Ещё одна полезная модель:

**o cafea → două cafele**
**о кафе́а → до́уэ кафе́ле**

кофе / одна чашка кофе → две чашки кофе

Например:

**Am comandat două cafele și am stat aproape două ore pe terasă.**

**Ам команда́т до́уэ кафе́ле ши ам стат апро́апе до́уэ о́ре пе тера́сэ.**

Мы заказали два кофе и просидели почти два часа на террасе.

Это хороший пример того, почему лучше знать plural конкретного частотного слова, а не пытаться вывести абсолютно всё из окончания singular.

---

# 11. Средний род: `-e` или `-uri`

У существительных среднего рода особенно часто встречаются две plural models:

> `-e`

и:

> `-uri`

---

## Средний род на `-e`

| Singular       | Транскрипция    | Plural          | Транскрипция     |
| -------------- | --------------- | --------------- | ---------------- |
| **apartament** | **апартаме́нт** | **apartamente** | **апартаме́нте** |
| **restaurant** | **рестора́нт**  | **restaurante** | **рестора́нте**  |
| **telefon**    | **телефо́н**    | **telefoane**   | **телефо́ане**   |
| **mesaj**      | **меса́ж**      | **mesaje**      | **меса́же**      |
| **oraș**       | **ора́ш**       | **orașe**       | **ора́ше**       |

---

## Средний род на `-uri`

| Singular  | Транскрипция | Plural       | Транскрипция  |
| --------- | ------------ | ------------ | ------------- |
| **hotel** | **хоте́л**   | **hoteluri** | **хоте́лурь** |
| **loc**   | **лок**      | **locuri**   | **ло́курь**   |
| **lucru** | **лу́кру**   | **lucruri**  | **лу́крурь**  |
| **birou** | **биро́у**   | **birouri**  | **биро́урь**  |

`-uri` — очень характерное румынское plural ending, которое ты будешь видеть постоянно.

---

# 12. `lucru → lucruri`

Это особенно важное слово.

**lucru**
**лу́кру**
вещь / дело / работа — в зависимости от контекста

**lucruri**
**лу́крурь**
вещи / дела

Например:

**Mai am câteva lucruri de făcut înainte să plec de acasă.**

**Май ам кы́тева лу́крурь де фэку́т ынаи́нте сэ плек де ака́сэ.**

Мне нужно сделать ещё несколько дел, прежде чем я выйду из дома.

Здесь `lucruri` очень естественно означает именно **дела / вещи, которые нужно сделать**, а не физические предметы.

---

# 13. Средний род снова виден через `două`

Из предыдущего reference уже знакома очень удобная модель.

### Masculine

**un prieten → doi prieteni**
**ун прие́тен → дой прие́тень**

### Feminine

**o mașină → două mașini**
**о маши́нэ → до́уэ маши́нь**

### Neuter

**un restaurant → două restaurante**
**ун рестора́нт → до́уэ рестора́нте**

Поэтому plural помогает определить род слова.

Если singular использует:

> `un`

а plural:

> `două`

перед нами типичный neuter.

---

# 14. Почему нельзя просто смотреть на окончание

Сравним:

**prieten → prieteni**
**прие́тен → прие́тень**

мужской род.

Но:

**mașină → mașini**
**маши́нэ → маши́нь**

женский род.

То есть окончание `-i` не означает автоматически:

> masculine.

---

То же самое с `-e`.

**fată → fete**
**фа́тэ → фе́те**

женский род.

Но:

**restaurant → restaurante**
**рестора́нт → рестора́нте**

средний род.

Поэтому plural ending — это часть системы, а не самостоятельный индикатор рода.

---

# 15. Изменение гласной внутри слова

Одна из наиболее непривычных особенностей румынского plural — изменение гласной внутри основы.

Например:

**masă → mese**
**ма́сэ → ме́се**

---

**stradă → străzi**
**стра́дэ →стрэ́зь**

---

**carte → cărți**
**ка́рте → кэрць**

---

**noapte → nopți**
**но́апте → нопць**

Это исторические изменения, и для практического уровня нет особого смысла пытаться каждый раз выводить их через сложную фонологическую теорию.

Полезнее постепенно запоминать распространённые пары.

---

# 16. Очень частые пары, которые стоит узнавать автоматически

| Singular       | Plural          | Транскрипция                   | Значение                  |
| -------------- | --------------- | ------------------------------ | ------------------------- |
| **om**         | **oameni**      | **ом → о́амень**               | человек → люди            |
| **băiat**      | **băieți**      | **бэя́т → бэе́ць**             | парень → парни            |
| **prieten**    | **prieteni**    | **прие́тен → прие́тень**       | друг → друзья             |
| **fată**       | **fete**        | **фа́тэ → фе́те**              | девушка → девушки         |
| **casă**       | **case**        | **ка́сэ → ка́се**              | дом → дома                |
| **mașină**     | **mașini**      | **маши́нэ → маши́нь**          | машина → машины           |
| **carte**      | **cărți**       | **ка́рте → кэрць**             | книга → книги             |
| **apartament** | **apartamente** | **апартаме́нт → апартаме́нте** | квартира → квартиры       |
| **restaurant** | **restaurante** | **рестора́нт → рестора́нте**   | ресторан → рестораны      |
| **telefon**    | **telefoane**   | **телефо́н → телефо́ане**      | телефон → телефоны        |

| **lucru**      | **lucruri**     | **лу́кру → лу́крурь**          | вещь / дело → вещи / дела |

---

# 17. Очень важное исключение: `om → oameni`

**om**
**ом**
человек

Plural:

**oameni**
**о́амень**
люди

**oameni**
IPA: /ˈo̯a.menʲ/

Это частотнейшее слово, и здесь почти бессмысленно пытаться вычислить plural из singular.

Нужно просто знать пару:

> **om → oameni**

Например:

**În București sunt foarte mulți oameni din alte țări, mai ales în zonele centrale ale orașului.**

**Ын Букурэ́шть сунт фо́арте мульць о́амень дин а́лте цэрь, май але́с ын зо́неле чентра́ле але ора́шулуй.**

В Бухаресте много людей из других стран, особенно в центральных районах города.

---

# 18. Plural и прилагательные

Когда существительное становится plural, прилагательное тоже должно согласоваться с ним.

### Singular

**un restaurant bun**
**ун рестора́нт бун**

хороший ресторан

### Plural

**două restaurante bune**
**до́уэ рестора́нте бу́не**

два хороших ресторана

---

Другой пример:

**o mașină nouă**
**о маши́нэ но́уэ**

новая машина

**două mașini noi**
**до́уэ маши́нь ной**

две новые машины

Это означает, что plural нужно узнавать не изолированно: он влияет и на соседние слова.

---

# 19. Plural в настоящих предложениях

## Пример 1

**În cartierul meu sunt câteva restaurante bune, dar în weekend aproape toate sunt foarte aglomerate.**

**Ын карти́ерул меу сунт кы́тева рестора́нте бу́не, дар ын уи́кенд апро́апе то́ате сунт фо́арте агломера́те.**

В моём районе есть несколько хороших ресторанов, но на выходных почти все они очень переполнены.

Здесь:

**restaurant → restaurante**
**рестора́нт → рестора́нте**

---

## Пример 2

**Am văzut două apartamente ieri, dar niciunul nu era suficient de aproape de metrou.**

**Ам вэзут до́уэ апартаме́нте йерь, дар ничу́нул ну е́ра суфичие́нт де апро́апе де метро́у.**

Вчера я посмотрел две квартиры, но ни одна не находилась достаточно близко к метро.

**apartament → apartamente**
**апартаме́нт → апартаме́нте**

---

## Пример 3

**În ultima perioadă am cumpărat mai multe cărți decât pot să citesc într-o lună.**

**Ын у́лтима перио́адэ ам кумпэра́т май му́лте кэрць декы́т пот сэ читэ́ск ынтро лу́нэ.**

В последнее время я купил больше книг, чем могу прочитать за месяц.

**carte → cărți**
**ка́рте → кэрць**

---

## Пример 4

**Câțiva prieteni de-ai mei vor să mergem la mare în septembrie, când sunt mai puțini turiști.**

**Кы́цива прие́тень де-ай ме́й вор сэ ме́рджем ла ма́ре ын септе́мбрие, кынд сунт май пуци́нь тури́шть.**

Несколько моих друзей хотят, чтобы мы поехали к морю в сентябре, когда туристов меньше.

Здесь сразу два masculine plurals:

**prieten → prieteni**
**прие́тен → прие́тень**

**turist → turiști**
**тури́ст → тури́шть**

---

# 20. `doi` и `două`

Plural тесно связан с формой числа «два».

### Мужской

**doi prieteni**
**дой прие́тень**
два друга

**doi colegi**
**дой коле́джь**
два коллеги

### Женский

**două mașini**
**до́уэ маши́нь**
две машины

**două străzi**
**до́уэ стрэ́зь**
две улицы

### Средний

**două apartamente**
**до́уэ апартаме́нте**

**două restaurante**
**до́уэ рестора́нте**

Потому что neuter в plural ведёт себя как feminine.

---

# 21. Французский здесь помогает только частично

Во французском plural обычно значительно проще на письме:

> un restaurant → des restaurants
> une voiture → des voitures

Хотя произношение множественного числа во французском имеет свои сложности, само существительное часто изменяется довольно предсказуемо.

В румынском же гораздо чаще меняется форма самого существительного:

> **carte → cărți**

> **masă → mese**

> **telefon → telefoane**

Поэтому французский здесь помогает понять концепцию числа и согласования, но не даёт готового алгоритма образования румынского plural.

---

# 22. Английская модель здесь слишком простая

В английском очень часто достаточно:

> restaurant → restaurants
> friend → friends
> apartment → apartments

Есть исключения вроде:

> person → people

Но в румынском разнообразие plural forms является нормальной частью системы, а не небольшой группой исключений.

Поэтому нельзя переносить английскую привычку:

> «знаю singular — значит автоматически построю plural».

---

# 23. Как практически запоминать новые существительные

Для самых полезных слов лучше хранить три элемента.

### Мужской

**un prieten → doi prieteni**
**ун прие́тен → дой прие́тень**
друг → друзья

### Женский

**o mașină → două mașini**
**о маши́нэ → до́уэ маши́нь**
машина → машины

### Средний

**un apartament → două apartamente**
**ун апартаме́нт → до́уэ апартаме́нте**
квартира → квартиры

Так одна запись одновременно показывает:

> singular + plural + gender.

# 24. Основные модели в одной таблице

| Модель             | Пример                       | Транскрипция                 |
| ------------------ | ---------------------------- | ---------------------------- |
| masculine → `-i`   | **prieten → prieteni**       | **прие́тен → прие́тень**     |
| feminine `-ă → -e` | **fată → fete**              | **фа́тэ → фе́те**            |
| feminine → `-i`    | **mașină → mașini**          | **маши́нэ → маши́нь**        |
| изменение основы   | **carte → cărți**            | **ка́рте → кэрць**           |
| neuter → `-e`      | **restaurant → restaurante** | **рестора́нт → рестора́нте** |
| neuter → `-uri`    | **hotel → hoteluri**         | **хоте́л → хоте́лурь**       |
| irregular          | **om → oameni**              | **ом → о́амень**             |

Эти модели покрывают огромное количество слов, которые будут постоянно встречаться в повседневном румынском.

Главное — не пытаться превратить их в абсолютные правила.

Для частотного существительного полезнее один раз запомнить:

**o carte → două cărți**
**о ка́рте → до́уэ кэрць**

чем каждый раз пытаться заново вычислять plural по окончанию.

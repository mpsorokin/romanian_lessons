# Verbele reflexive

**Ве́рбеле рефлекси́ве**

Возвратные глаголы

В румынском очень часто встречаются конструкции:

**mă duc**

**мэ дук**

я иду / ухожу

**mă uit**

**мэ уйт**

я смотрю

**mă simt**

**мэ симт**

я себя чувствую

**mă trezesc**

**мэ трезе́ск**

я просыпаюсь

**ne întâlnim**

**не ынтылни́м**

мы встречаемся

Общая система строится вокруг коротких местоимений:

**mă / te / se / ne / vă / se**

**мэ / те / се / не / вэ / се**

Но важно не пытаться каждый раз переводить их русским «себя».

У многих очень частых румынских глаголов возвратная форма является просто частью самого глагола.

Например:

**a se uita**

**а се уйта́**

смотреть

Буквально переводить это как «смотреть себя» нельзя.

Для понимания живой речи конструкции вроде **mă duc**, **mă uit**, **mă simt** лучше постепенно превращать в готовые смысловые блоки.

---

# 1. Главная система

| Persoană             | Pronume reflexiv | Пример                     |
| -------------------- | ---------------- | -------------------------- |
| eu — еу              | **mă** — мэ      | **mă uit** — мэ уйт        |
| tu — ту              | **te** — те      | **te uiți** — те уйць      |
| el / ea — ел / я     | **se** — се      | **se uită** — се у́йтэ     |
| noi — ной            | **ne** — не      | **ne uităm** — не уйтэ́м   |
| voi — вой            | **vă** — вэ      | **vă uitați** — вэ уйта́ць |
| ei / ele — ей / е́ле | **se** — се      | **se uită** — се у́йтэ     |

Базовая схема:

> **reflexive pronoun + verb**

Например:

**mă simt**

**мэ симт**

я себя чувствую

**te simți**

**те симць**

ты себя чувствуешь

**se simte**

**се си́мте**

он / она себя чувствует

---

# 2. Что означает se в словаре

В словаре возвратный или pronominal verb обычно записывается через:

**a se + verb**

**а се + глагол**

Например:

**a se trezi**

**а се трези́**

просыпаться

**a se întâlni**

**а се ынтылни́**

встречаться

**a se duce**

**а се ду́че**

идти / уходить

Но **se** здесь не означает, что в реальном предложении всегда будет именно **se**.

Форма меняется по лицам:

**a se trezi**

**а се трези́**

→

**mă trezesc**

**мэ трезе́ск**

я просыпаюсь

→

**te trezești**

**те трезе́шть**

ты просыпаешься

→

**se trezește**

**се трезе́ште**

он / она просыпается

---

# 3. Полная таблица местоимений

| Лицо                 | Форма       |
| -------------------- | ----------- |
| eu — еу              | **mă** — мэ |
| tu — ту              | **te** — те |
| el / ea — ел / я     | **se** — се |
| noi — ной            | **ne** — не |
| voi — вой            | **vă** — вэ |
| ei / ele — ей / е́ле | **se** — се |

Эти формы чрезвычайно частотны и обычно произносятся без сильного логического ударения.

Поэтому в реальной речи важно научиться слышать:

**mă**

**мэ**

**te**

**те**

**se**

**се**

почти как маленькие части большого глагольного блока.

---

# 4. Первый тип: настоящее действие действительно направлено на себя

Самый понятный тип похож на русский возвратный глагол.

**a se spăla**

**а се спэла́**

мыться

**Mă spăl înainte să plec la serviciu.**

**Мэ спэл ынаи́нте сэ плек ла серви́чиу.**

Я моюсь перед тем, как уйти на работу.

Здесь действительно можно представить:

> я мою себя.

---

# 5. a se îmbrăca

**a se îmbrăca**

**а се ымбрэка́**

одеваться

**Mă îmbrac repede și plec, pentru că deja sunt în întârziere.**

**Мэ ымбра́к ре́педе ши плек, пе́нтру кэ де́жа сунт ын ынтырзие́ре.**

Я быстро одеваюсь и ухожу, потому что уже опаздываю.

Здесь русское возвратное значение тоже довольно прозрачное:

**mă îmbrac**

**мэ ымбра́к**

одеваюсь

---

# 6. Но многие румынские reflexive verbs не переводятся русским «-ся»

Очень важные примеры:

**mă duc**

**мэ дук**

я иду / ухожу

**mă uit**

**мэ уйт**

я смотрю

**mă simt**

**мэ симт**

я себя чувствую

Русский перевод может вообще не содержать «себя» или `-ся`.

Поэтому термин «возвратный глагол» описывает румынскую грамматическую форму, а не обязательно русский перевод.

---

# 7. a se uita — смотреть

**a se uita**

**а се уйта́**

смотреть

Это один из самых важных возвратных глаголов.

| Persoană             | Formă                      |
| -------------------- | -------------------------- |
| eu — еу              | **mă uit** — мэ уйт        |
| tu — ту              | **te uiți** — те уйць      |
| el / ea — ел / я     | **se uită** — се у́йтэ     |
| noi — ной            | **ne uităm** — не уйтэ́м   |
| voi — вой            | **vă uitați** — вэ уйта́ць |
| ei / ele — ей / е́ле | **se uită** — се у́йтэ     |

---

# 8. a se uita la

Обычно после **a se uita** используется:

**la**

**ла**

на / к

То есть:

**a se uita la ceva**

**а се уйта́ ла чева́**

смотреть на что-то

**Mă uit la meniul restaurantului înainte să aleg ce vreau să comand.**

**Мэ уйт ла ме́ниул рестау́рантулуй ынаи́нте сэ але́г че вряу сэ кома́нд.**

Я смотрю меню ресторана перед тем, как выбрать, что хочу заказать.

---

# 9. Смотреть фильм или сериал

**Mă uit la un serial pe Netflix.**

**Мэ уйт ла ун сериа́л пе Не́тфликс.**

Я смотрю сериал на Netflix.

**Te uiți la filmul ăsta sau doar stai pe telefon?**

**Те уйць ла фи́лмул э́ста сау доар стай пе телефо́н?**

Ты смотришь этот фильм или просто сидишь в телефоне?

Здесь **a se uita la** функционально соответствует английскому:

> to watch / to look at

---

# 10. Очень важная ловушка: a uita vs a se uita

Без reflexive pronoun:

**a uita**

**а уйта́**

забывать

С reflexive pronoun:

**a se uita**

**а се уйта́**

смотреть

Сравните:

**Uit mereu unde pun cheile.**

**Уйт мере́у у́нде пун ке́иле.**

Я постоянно забываю, куда кладу ключи.

Но:

**Mă uit unde am pus cheile.**

**Мэ уйт у́нде ам пус ке́иле.**

Я смотрю, куда положил ключи.

Один маленький **mă** полностью меняет значение глагола.

| tu — ту              | **te simți** — те симць      |
| el / ea — ел / я     | **se simte** — се си́мте     |
| noi — ной            | **ne simțim** — не симци́м   |
| voi — вой            | **vă simțiți** — вэ симци́ць |
| ei / ele — ей / е́ле | **se simt** — се симт        |

---

# 12. mă simt bine

Очень частый chunk:

**mă simt bine**

**мэ симт би́не**

я хорошо себя чувствую

**Mă simt mult mai bine azi decât ieri.**

**Мэ симт мулт май би́не азь декы́т йерь.**

Сегодня я чувствую себя намного лучше, чем вчера.

---

# 13. mă simt obosit

**Mă simt puțin obosit după o zi întreagă la birou.**

**Мэ симт пуци́н обоси́т ду́пэ о зи ынтря́гэ ла биро́у.**

Я чувствую себя немного уставшим после целого дня в офисе.

Согласование идёт с человеком:

**Mă simt obosit.**

**Мэ симт обоси́т.**

Я чувствую себя уставшим.

**Mă simt obosită.**

**Мэ симт обоси́тэ.**

Я чувствую себя уставшей.

---

# 14. Cum te simți?

Один из самых частых вопросов:

**Cum te simți?**

**Кум те симць?**

Как ты себя чувствуешь?

**Cum te simți după călătorie?**

**Кум те симць ду́пэ кэлэтори́е?**

Как ты себя чувствуешь после поездки?

В быстрой речи **te simți** часто воспринимается почти как единый блок.

# 16. Реальный пример с a se trezi

**De obicei mă trezesc devreme în timpul săptămânii, dar în weekend încerc să dorm mai mult.**

**Де обиче́й мэ трезе́ск девре́ме ын ти́мпул сэптэмы́ний, дар ын уикэ́нд ынче́рк сэ дорм май мулт.**

Обычно я просыпаюсь рано в течение недели, но на выходных стараюсь поспать подольше.

| el / ea — ел / я     | **se întâlnește** — се ынтылне́ште |
| noi — ной            | **ne întâlnim** — не ынтылни́м     |
| voi — вой            | **vă întâlniți** — вэ ынтылни́ць   |
| ei / ele — ей / е́ле | **se întâlnesc** — се ынтылне́ск   |

---

# 18. mă întâlnesc cu

Частая конструкция:

**a se întâlni cu cineva**

**а се ынтылни́ ку чинева́**

встретиться с кем-то

**Mă întâlnesc cu niște prieteni în centru după serviciu.**

**Мэ ынтылне́ск ку ни́ште приете́нь ын че́нтру ду́пэ серви́чиу.**

Я встречаюсь с друзьями в центре после работы.

---

# 19. ne întâlnim

Очень частая форма:

**Ne întâlnim la metrou.**

**Не ынтылни́м ла метро́у.**

Встретимся у метро.

**Ne întâlnim pe la opt și după mergem să mâncăm ceva.**

**Не ынтылни́м пе ла опт ши ду́пэ ме́рджем сэ мынкэ́м чева́.**

Встречаемся примерно в восемь, а потом идём что-нибудь поесть.

Здесь **ne** имеет уже почти взаимное значение:

> мы встречаем друг друга.

---

# 20. Reflexive и reciprocal meaning

Одна и та же система может выражать:

### настоящее возвратное действие

**Se spală.**

**Се спа́лэ.**

Он / она моется.

### взаимное действие

**Se întâlnesc.**

**Се ынтылне́ск.**

Они встречаются.

Вторая конструкция логически означает:

> они встречают друг друга.

Такое значение называется reciprocal — взаимным.

---

# 21. ne vedem — увидимся

Очень частый reciprocal chunk:

**Ne vedem mâine.**

**Не веде́м мы́йне.**

Увидимся завтра.

Формально **a vedea** сам по себе не возвратный глагол:

**văd**

**вэд**

я вижу

Но:

**ne vedem**

**не веде́м**

буквально «мы видим друг друга» → «увидимся».

Это один из самых распространённых способов попрощаться.

---

# 22. ne auzim

Ещё один очень живой chunk:

**Ne auzim mai târziu.**

**Не аузи́м май тырзи́у.**

Созвонимся / спишемся / будем на связи позже.

Буквально:

> услышим друг друга позже.

В реальной коммуникации это часто примерно:

> Talk to you later.

---

# 23. ne ajutăm

**Ne ajutăm când avem multă treabă.**

**Не ажутэ́м кынд аве́м му́лтэ тря́бэ.**

Мы помогаем друг другу, когда у нас много работы.

Здесь **ne** = друг друга.

---

# 24. se cunosc

**Se cunosc de mulți ani.**

**Се куно́ск де мулць ань.**

Они знают друг друга много лет.

Форма **se** здесь тоже reciprocal.

То есть не нужно автоматически переводить:

**se**

**се**

как «себя».

Иногда это:

> друг друга.

---

# 25. a se duce — идти / уходить

Один из самых важных разговорных глаголов:

**a se duce**

**а се ду́че**

идти / уходить / отправляться

| Persoană             | Formă                      |
| -------------------- | -------------------------- |
| eu — еу              | **mă duc** — мэ дук        |
| tu — ту              | **te duci** — те дучь      |
| el / ea — ел / я     | **se duce** — се ду́че     |
| noi — ной            | **ne ducem** — не дуче́м   |
| voi — вой            | **vă duceți** — вэ дуче́ць |
| ei / ele — ей / е́ле | **se duc** — се дук        |

Этот глагол очень частотный и сильно irregular.

---

# 26. mă duc = я иду / ухожу

**Mă duc la supermarket și după mă întorc acasă.**

**Мэ дук ла супермарке́т ши ду́пэ мэ ынто́рк ака́сэ.**

Я иду в супермаркет, а потом возвращаюсь домой.

Не нужно переводить **mă** отдельно.

Весь блок:

**mă duc**

**мэ дук**

= я иду / я отправляюсь / я ухожу.

---

# 27. mă duc vs merg

Оба варианта могут переводиться как «я иду».

**Merg la birou cu metroul.**

**Мердж ла биро́у ку метро́ул.**

Я еду в офис на метро.

**Mă duc la birou acum.**

**Мэ дук ла биро́у аку́м.**

Я сейчас еду / отправляюсь в офис.

Очень грубо:

**a merge**

**а ме́рдже**

нейтральное движение / идти / ехать

**a se duce**

**а се ду́че**

часто подчёркивает отправление куда-то, уход или перемещение от текущей точки.

Но в разговорной речи области употребления сильно пересекаются.

---

# 28. te duci unde?

**Unde te duci?**

**У́нде те дучь?**

Куда ты идёшь?

Это чрезвычайно естественный разговорный вопрос.

**Unde te duci după serviciu?**

**У́нде те дучь ду́пэ серви́чиу?**

Куда ты идёшь после работы?

---

# 29. se duce

**Se duce acasă pentru că mâine trebuie să se trezească devreme.**

**Се ду́че ака́сэ пе́нтру кэ мы́йне трэ́буе сэ се трезя́скэ девре́ме.**

Он / она идёт домой, потому что завтра нужно рано проснуться.

Здесь сразу два reflexive blocks:

**se duce**

**се ду́че**

и:

**să se trezească**

**сэ се трезя́скэ**

# 33. Cum te numești?

**Cum te numești?**

**Кум те нуме́шть?**

Как тебя зовут?

Ответ:

**Mă numesc Andrei.**

**Мэ нуме́ск Андре́й.**

Меня зовут Андрей.

По структуре это близко к французскому:

> *Je m'appelle...*

То есть reflexive construction для имени уже должна быть знакома интуитивно через французский.

---

# 34. se numește для мест и вещей

Не только люди:

**Restaurantul se numește Caru' cu Bere.**

**Рестау́рантул се нуме́ште Ка́ру ку Бе́ре.**

Ресторан называется Caru' cu Bere.

**Strada asta se numește Calea Victoriei.**

**Стра́да а́ста се нуме́ште Ка́ля Викторие́й.**

Эта улица называется Calea Victoriei.

---

# 35. a se grăbi — спешить

**a se grăbi**

**а се грэби́**

спешить

**Mă grăbesc, pentru că metroul vine în două minute.**

**Мэ грэбе́ск, пе́нтру кэ метро́ул ви́не ын до́уэ мину́те.**

Я спешу, потому что метро придёт через две минуты.

**Nu te grăbi, avem destul timp.**

**Ну те грэби́, аве́м десту́л тимп.**

Не спеши, у нас достаточно времени.

---

# 36. a se odihni — отдыхать

**а се одихни́**

отдыхать

**În weekend încerc să mă odihnesc mai mult și să nu mă gândesc tot timpul la muncă.**

**Ын уикэ́нд ынче́рк сэ мэ одихне́ск май мулт ши сэ ну мэ гынде́ск тот ти́мпул ла му́нкэ.**

На выходных я стараюсь больше отдыхать и не думать постоянно о работе.

# 37. a se gândi — думать

**a se gândi**

**а се гынди́**

думать / задумываться

Часто используется с:

**la**

**ла**

о / на

**Mă gândesc să schimb apartamentul anul viitor.**

**Мэ гынде́ск сэ скимб апартаме́нтул а́нул виито́р.**

Я думаю о том, чтобы сменить квартиру в следующем году.

# 38. mă gândesc la

**Mă gândesc la vacanța de luna viitoare.**

**Мэ гынде́ск ла вака́нца де лу́на виито́аре.**

Я думаю об отпуске в следующем месяце.

Здесь английский использует:

> think about

а румынский:

**a se gândi la**

**а се гынди́ ла**

# 39. a se muta — переезжать

**a se muta**

**а се мута́**

переезжать

**Mă mut într-un apartament nou luna viitoare.**

**Мэ мут ынтр-ун апартаме́нт ноу лу́на виито́аре.**

Я переезжаю в новую квартиру в следующем месяце.

Ты хочешь переехать ближе к центру?

# 40. a se opri — останавливаться

**а се опри́**

**Metroul se oprește la Piața Victoriei.**

**Метро́ул се опре́ште ла Пья́ца Викторие́й.**

Метро останавливается на Piața Victoriei.

**Mă opresc la supermarket înainte să ajung acasă.**

**Мэ опре́ск ла супермарке́т ынаи́нте сэ ажу́нг ака́сэ.**

Я зайду / остановлюсь у супермаркета перед тем, как прийти домой.

# 41. a se așeza — садиться

**a se așeza**

**а се ашеза́**

садиться / располагаться

**Ne așezăm la o masă lângă fereastră.**

**Не ашезэ́м ла о ма́сэ лы́нгэ феря́стрэ.**

Мы садимся за столик возле окна.

Очень часто в ресторане или кафе можно услышать формы этого глагола.

---

# 42. Reflexive pronoun vs direct object pronoun

Формы:

**mă / te / ne / vă**

**мэ / те / не / вэ**

совпадают с формами direct object pronouns.

Поэтому нужно различать структуру по глаголу.

Сравните:

**Mă vede.**

**Мэ ве́де.**

Он / она видит меня.

Здесь:

**mă**

**мэ**

= меня.

Но:

**Mă uit.**

**Мэ уйт.**

Я смотрю.

Здесь **mă** — часть возвратной формы **a se uita**.

---

# 43. Ещё одна пара

**Te văd la metrou.**

**Те вэд ла метро́у.**

Я вижу тебя у метро.

Здесь:

**te**

**те**

= тебя.

Но:

**Te duci la metrou.**

**Те дучь ла метро́у.**

Ты идёшь к метро.

Здесь **te** относится к подлежащему «ты» и является частью:

**a se duce**

**а се ду́че**

---

# 44. Как быстро отличать эти два случая

Очень полезный практический вопрос:

> Кто выполняет действие?

**Mă vede.**

**Мэ ве́де.**

Подразумеваемое подлежащее:

> он / она.

Объект:

> меня.

Но:

**Mă duc.**

**Мэ дук.**

Подлежащее:

> я.

**mă** относится к тому же человеку.

Именно это является классической reflexive relationship.

---

# 45. Subject pronoun обычно опускается

Можно сказать:

**Eu mă duc acasă.**

**Еу мэ дук ака́сэ.**

Я иду домой.

Но обычно достаточно:

**Mă duc acasă.**

**Мэ дук ака́сэ.**

Я иду домой.

Глагольная форма **duc** и местоимение **mă** уже показывают первое лицо.

---

# 46. Нельзя просто убрать reflexive pronoun

Если глагол лексически возвратный, местоимение является частью конструкции.

Нормально:

**Mă uit la film.**

**Мэ уйт ла филм.**

Я смотрю фильм.

Но:

**Uit filmul.**

**Уйт фи́лмул.**

означало бы уже не «я смотрю фильм», а что-то связанное с глаголом **a uita** — забывать.

То есть pronoun иногда полностью определяет значение глагола.

---

# 47. Отрицание: nu + reflexive pronoun + verb

Очень стабильный порядок:

**nu mă duc**

**ну мэ дук**

я не иду

**nu te uiți**

**ну те уйць**

ты не смотришь

**nu se simte**

**ну се си́мте**

он / она плохо себя чувствует / не чувствует себя...

**nu ne întâlnim**

**ну не ынтылни́м**

мы не встречаемся

---

# 48. Реальный пример отрицания

**Nu mă duc în centru azi, pentru că sunt obosit și vreau să rămân acasă.**

**Ну мэ дук ын че́нтру азь, пе́нтру кэ сунт обоси́т ши вряу сэ рэмын ака́сэ.**

Сегодня я не еду в центр, потому что устал и хочу остаться дома.

---

# 49. nu mai + reflexive verb

Очень частая комбинация:

**nu mă mai duc**

**ну мэ май дук**

я больше не иду / уже не хожу

**Nu mă mai duc la restaurantul ăla, pentru că ultima dată serviciul a fost foarte slab.**

**Ну мэ май дук ла рестау́рантул э́ла, пе́нтру кэ у́лтима да́тэ серви́чиул а фост фо́арте слаб.**

Я больше не хожу в тот ресторан, потому что в прошлый раз обслуживание было очень плохим.

---

# 50. После să reflexive pronoun остаётся перед глаголом

Структура:

> **să + reflexive pronoun + verb**

Например:

**să mă duc**

**сэ мэ дук**

чтобы я пошёл / мне пойти

**să te uiți**

**сэ те уйць**

чтобы ты посмотрел

**să se trezească**

**сэ се трезя́скэ**

чтобы он / она проснулся / проснулась

# 51. vreau să mă duc

Я хочу поехать к морю на выходных, если погода будет хорошей.

Здесь можно воспринимать цепочку блоками:

**vreau să**

**вряу сэ**

я хочу...

# 53. pot să mă întâlnesc

**Pot să mă întâlnesc cu tine după șase, dacă termin munca la timp.**

**Пот сэ мэ ынтылне́ск ку ти́не ду́пэ ша́се, да́кэ терми́н му́нка ла тимп.**

Я могу встретиться с тобой после шести, если закончу работу вовремя.

# 54. Будущее с o să

Reflexive pronoun ставится после **să**:

**o să mă duc**

**о сэ мэ дук**

я пойду

**o să te sun**

**о сэ те сун**

я тебе позвоню

**o să ne întâlnim**

**о сэ не ынтылни́м**

мы встретимся

Например:

**O să ne întâlnim direct la restaurant.**

**О сэ не ынтылни́м дире́кт ла рестора́нт.**

Мы встретимся прямо в ресторане.

# 55. Прошедшее: очень важные listening forms

В **Perfectul compus** reflexive pronouns соединяются со вспомогательным глаголом.

Очень частые формы:

**m-am dus**

**мам дус**

я пошёл / ушёл

**te-ai dus**

**тяй дус**

ты пошёл / ушёл

**s-a dus**

**са дус**

он / она пошёл / ушла

**ne-am dus**

**ням дус**

мы пошли

**v-ați dus**

**ваць дус**

вы пошли

**s-au dus**

**сау дус**

они пошли

Полная система прошедшего разбирается отдельно, но эти склейки нужно узнавать на слух заранее.

# 56. m-am trezit

**M-am trezit foarte devreme și n-am mai putut să adorm.**

**Мам трези́т фо́арте девре́ме ши нам май путу́т сэ адо́рм.**

Я проснулся очень рано и больше не смог заснуть.

В быстрой речи:

**m-am**

**мам**

звучит как один короткий блок.

---

# 57. s-a dus

Очень частая разговорная конструкция:

**S-a dus acasă.**

**Са дус ака́сэ.**

Он / она ушёл / ушла домой.

В listening не нужно пытаться отдельно услышать:

**se + a**

Письменная форма уже сокращается до:

**s-a**

**са**

---

# 58. s-au dus

**S-au dus în centru după concert.**

**Сау дус ын че́нтру ду́пэ конче́рт.**

Они пошли в центр после концерта.

Сравните:

**s-a dus**

**са дус**

он / она ушёл

**s-au dus**

**сау дус**

они ушли

Разница на слух очень небольшая, но грамматически важная.

---

# 59. Reflexive pronouns в connected speech

Отдельно:

**mă duc**

**мэ дук**

Но в нормальной речи это звучит практически как один ритмический блок.

То же самое:

**te duci**

**те дучь**

**se duce**

**се ду́че**

**mă uit**

**мэ уйт**

**te uiți**

**те уйць**

**ne vedem**

**не веде́м**

Для comprehension полезнее слышать весь chunk, а не пытаться сначала распознать маленькое местоимение, а потом глагол.

# 61. French bridge

Если знаком французский, сама reflexive system очень узнаваема.

| Romanian    | Français | Значение                |
| ----------- | -------- | ----------------------- |
| **mă** — мэ | me       | себя / возвратная форма |
| **te** — те | te       | себя                    |
| **se** — се | se       | себя                    |
| **ne** — не | nous     | себя / друг друга       |
| **vă** — вэ | vous     | себя                    |
| **se** — се | se       | себя / друг друга       |

Например:

**Mă trezesc devreme.**

**Мэ трезе́ск девре́ме.**

Французский:

> *Je me réveille tôt.*

Или:

**Ne întâlnim mâine.**

**Не ынтылни́м мы́йне.**

Французский:

> *On se voit demain.*

Логика очень похожа.

---

# 62. Но нельзя переносить французские глаголы один к одному

Даже если система pronouns похожа, конкретный глагол может быть reflexive в одном языке и обычным в другом.

Поэтому полезно переносить именно грамматическую модель:

> pronoun + verb

но не предполагать автоматически, что каждый французский reflexive verb будет reflexive и в румынском.

---

# 63. Главные lexical reflexives

Некоторые глаголы стоит хранить в памяти именно вместе с **se**.

| Infinitiv                          | Значение         |
| ---------------------------------- | ---------------- |
| **a se uita** — а се уйта́         | смотреть         |
| **a se simți** — а се симци́       | чувствовать себя |
| **a se trezi** — а се трези́       | просыпаться      |
| **a se întâlni** — а се ынтылни́   | встречаться      |
| **a se duce** — а се ду́че         | идти / уходить   |
| **a se întoarce** — а се ынтоа́рче | возвращаться     |
| **a se numi** — а се нуми́         | называться       |
| **a se grăbi** — а се грэби́       | спешить          |
| **a se odihni** — а се одихни́     | отдыхать         |
| **a se gândi** — а се гынди́       | думать           |
| **a se muta** — а се мута́         | переезжать       |
| **a se opri** — а се опри́         | останавливаться  |

Учить только:

**uita**

**уйта́**

вместо:

**a se uita**

**а се уйта́**

опасно, потому что значение без **se** может быть совершенно другим.

---

# 64. se может появляться без конкретного «себя»

В румынском существуют конструкции, где **se** является частью глагольной структуры, но никакого реального человека, который «делает что-то с собой», нет.

Например:

**Se întâmplă.**

**Се ынты́мплэ.**

Случается. / Такое бывает.

**Ce se întâmplă?**

**Че се ынты́мплэ?**

Что происходит?

Здесь переводить **se** отдельным «себя» бессмысленно.

---

# 65. Ce s-a întâmplat?

Сверхчастый прошедший chunk:

**Ce s-a întâmplat?**

**Че са ынтымпла́т?**

Что случилось?

В живой речи весь блок:

**s-a întâmplat**

**са ынтымпла́т**

нужно постепенно узнавать целиком.

---

# 66. se poate

Ещё одна очень частая impersonal construction:

**Se poate?**

**Се по́ате?**

Можно?

**Se poate plăti cu cardul?**

**Се по́ате плэти́ ку ка́рдул?**

Можно заплатить картой?

Здесь **se** тоже не означает конкретное «себя».

Функция конструкции:

> можно / возможно.

---

# 67. se vede

**Se vede foarte bine de aici.**

**Се ве́де фо́арте би́не де аичь.**

Отсюда очень хорошо видно.

Здесь:

**se vede**

**се ве́де**

≈ видно.

Это уже impersonal/passive-like использование **se**.

На уровне A1–B1 важнее узнавать смысл, чем пытаться сразу классифицировать каждый случай академически.

---

# 68. se spune

**Se spune că zona asta este foarte bună.**

**Се спу́не кэ зо́на а́ста е́сте фо́арте бу́нэ.**

Говорят, что этот район очень хороший.

Здесь:

**se spune**

**се спу́не**

= говорят / принято говорить.

Не:

> «он говорит себя».

---

# 69. Три основных значения se, которые реально нужно различать

### 1. Настоящее возвратное

**Se spală.**

**Се спа́лэ.**

Он / она моется.

### 2. Взаимное

**Se întâlnesc.**

**Се ынтылне́ск.**

Они встречаются друг с другом.

### 3. Безличное / passive-like

**Se poate plăti cu cardul.**

**Се по́ате плэти́ ку ка́рдул.**

Можно заплатить картой.

И ещё есть большое количество lexical reflexive verbs, где **se** просто является частью словарной конструкции:

**se uită**

**се у́йтэ**

смотрит

# 70. Реальная бытовая цепочка

**Mă trezesc pe la șapte, mă îmbrac repede și mă duc la birou cu metroul. După serviciu mă întâlnesc uneori cu niște prieteni în centru, iar dacă nu sunt prea obosit, mă întorc acasă destul de târziu.**

Я просыпаюсь примерно в семь, быстро одеваюсь и еду в офис на метро. После работы иногда встречаюсь с друзьями в центре, а если не слишком устал, возвращаюсь домой довольно поздно.

# 71. Естественный диалог

**— Unde te duci după muncă?**

**— У́нде те дучь ду́пэ му́нкэ?**

Куда ты идёшь после работы?

**— Mă întâlnesc cu Andrei în centru.**

**— Мэ ынтылне́ск ку Андре́й ын че́нтру.**

Я встречаюсь с Андреем в центре.

**— Vă duceți undeva să mâncați?**

**— Вэ дуче́ць ундева́ сэ мынка́ць?**

Вы куда-нибудь идёте поесть?

**— Da, dar încă nu știm unde. Ne uităm acum la câteva restaurante.**

**— Да, дар ы́нкэ ну штим у́нде. Не уйтэ́м аку́м ла кы́тева рестора́нте.**

Да, но пока не знаем куда. Сейчас смотрим несколько ресторанов.

В этом маленьком диалоге reflexive pronouns постоянно меняются:

**te → mă → vă → ne**

**те → мэ → вэ → не**

в зависимости от лица.

# 76. Главное, что нужно распознавать автоматически

Если в реальной речи вы слышите:

**Mă duc.**

**Мэ дук.**

не нужно анализировать reflexive pronoun.

Сразу:

> я иду / ухожу.

Если слышите:

**Ne vedem.**

**Не веде́м.**

сразу:

> увидимся.

Если:

**Cum te simți?**

**Кум те симць?**

сразу:

> как ты себя чувствуешь?

Если:

**Ce se întâmplă?**

**Че се ынты́мплэ?**

сразу:

> что происходит?

Если:

**Se poate?**

**Се по́ате?**

сразу:

> можно?

Если:

**Mă uit.**

**Мэ уйт.**

сразу:

> смотрю.

Это намного полезнее для comprehension, чем умение формально определить тип каждого reflexive pronoun.

# 77. Сжатая карта системы

| Function | Romanian    |
| -------- | ----------- |
| я        | **mă** — мэ |
| ты       | **te** — те |
| он / она | **se** — се |
| мы       | **ne** — не |
| вы       | **vă** — вэ |
| они      | **se** — се |

Главные chunks:

| Конструкция                      | Значение              |
| -------------------------------- | --------------------- |
| **mă duc** — мэ дук              | иду / ухожу           |
| **mă uit** — мэ уйт              | смотрю                |
| **mă simt** — мэ симт            | чувствую себя         |
| **mă trezesc** — мэ трезе́ск     | просыпаюсь            |
| **mă întâlnesc** — мэ ынтылне́ск | встречаюсь            |
| **mă întorc** — мэ ынто́рк       | возвращаюсь           |
| **mă gândesc** — мэ гынде́ск     | думаю                 |
| **ne vedem** — не веде́м         | увидимся              |
| **ne auzim** — не аузи́м         | созвонимся / спишемся |
| **ne întâlnim** — не ынтылни́м   | встречаемся           |
| **se întâmplă** — се ынты́мплэ   | происходит            |
| **se poate** — се по́ате         | можно                 |
| **se spune** — се спу́не         | говорят               |

Главная практическая идея:

> **mă / te / se / ne / vă / se** нужно узнавать не как шесть отдельных слов со значением «себя», а как короткие грамматические элементы, которые входят в огромное количество готовых румынских глагольных конструкций.

Когда блоки вроде **mă duc**, **mă uit**, **mă simt**, **ne vedem**, **se poate** начинают распознаваться целиком, разговорный румынский становится заметно прозрачнее.
